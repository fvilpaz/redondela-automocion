# 🚗 Redondela Automoción · Digital Business Hub

Professional web platform for a specialized automotive workshop in Redondela.  
Designed to bridge the gap between traditional mechanical services and modern digital accessibility.

- 🛠️ **[View Live demo](https://fvilpaz.github.io/redondela-automocion/)**
- 📂 **[Repository](https://github.com/fvilpaz/redondela-automocion)**

---

## 📌 Project Overview

This project serves as the official digital storefront for **Redondela Automoción**. It is engineered to prioritize user trust and local SEO through a clean, mobile-first interface.

### Key Features:
* **Conversion Oriented:** Strategic placement of "Call to Action" buttons for direct contact.
* **Service Catalog:** Detailed breakdown of specialized mechanical services.
* **Trust Signals:** Integration of social proof and real-time location via Google Maps.
* **Fully Responsive:** Optimized for customers checking information from any device.

---

## 🛠 Tech Stack

* **HTML5 / CSS3:** Semantic structure and modern styling.
* **Flexbox Layout:** For a robust, fluid grid system.
* **Google Maps API:** Integration for precise customer navigation.
* **Git & GitHub:** Version control and automated deployment via GitHub Pages.
